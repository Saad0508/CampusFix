# CampusFix

CampusFix is a simple campus service and complaint management system created for the DevOps assignments.

## Purpose

The application allows users to submit campus complaints and view recent complaints.

## Technology Stack

- Python
- Flask
- HTML
- CSS
- Git
- GitHub

## Project Structure

```text
CampusFix/
├── app.py
├── README.md
├── requirements.txt
├── .gitignore
├── templates/
│   └── index.html
└── static/
    └── style.css
```

## Run the Application

Create and activate a virtual environment if desired, then install dependencies:

```bash
pip install -r requirements.txt
```

Start the application:

```bash
python app.py
```

Open the local address shown by Flask in your browser.
